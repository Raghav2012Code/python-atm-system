# 🏦 Python ATM System

A simple command-line ATM simulator built with Python.  
This project demonstrates core programming concepts like loops, conditionals, input validation, and PIN authentication.

![Python Version](https://img.shields.io/badge/python-3.x-blue.svg)
![GitHub last commit](https://img.shields.io/github/last-commit/Raghav2012Code/python-atm-system)

## ✨ Features

- 🔐 **PIN authentication** – 3 incorrect attempts block the card  
- 💸 **Withdraw money** – checks for insufficient balance and invalid amounts  
- 💰 **Deposit money** – adds to balance with validation  
- 📊 **Check balance** – displays current balance  
- 🔁 **Menu loop** – repeats until user chooses exit  
- 🚫 **Input validation** – prevents negative or zero transactions  

## 🔑 Default PIN 3075


> ⚠️ You can change the PIN by modifying the `correct_pin` variable inside `main.py`.

3. Open a terminal in the project folder.
